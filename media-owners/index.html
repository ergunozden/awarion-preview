FOR MEDIA OWNERS

Frequently Asked Questions

Monetizing your DOOH network with Awarion Centrum and Junction SSP, answered.

Awarion Centrum is a CMS that allows media owners to activate their direct campaigns in a couple of minutes. It's built from the ground up for DOOH advertising networks. Centrum has a native connection to Junction SSP which connects media owners to programmatic demand via the Junction marketplace. Owners using an external CMS can still connect to Junction SSP, which integrates with Broadsign, Scala, and custom architectures.
Media owners monetize inventory by onboarding screens to Awarion Centrum and Junction SSP to capture programmatic demand. Commercial frameworks feature self-service models with a tech fee or managed-service structures, running on tailored per-screen monthly subscriptions for Centrum.
Any screen type and network size can join, as there are no minimum inventory requirements. Roadside billboards, transit, malls, in-venue displays, and single-screen operations use Centrum or Junction SSP, gaining UI access for creative approval and revenue tracking.
Awarion Centrum differs because it is a dedicated DOOH media owner CMS featuring device-level reporting and granular campaign prioritization controls, whereas general digital signage CMSs are not tailored to advertising needs and are usually based on creating manual loops and removing content manually. Centrum CMS is different in that it enables media owners to set and forget campaigns.
Media owners can start fast thanks to a streamlined technical setup. Registering a screen takes roughly 15 minutes, while player installation requires only 5 minutes, supported by bulk onboarding, fast pricing implementation, and dedicated training. The platform supports private marketplace deals with always-on pricing, per-customer rates, and defined end-dates. Approvals can be given to creative-screen pairings, allowing for greater flexibility.
